# Introduction to Scipy
Scipy is collection of functions built on Numpy.

# Subpackages 
Scipy is divided into subpackages for covering different domains of science and mathematics.

cluster ~ comes with clustering algorithms.
constants ~ Physics and Maths related data.
differentiate ~ Differentiation tools for functions.
fft ~ Allows us to perform fourier transforms.
fftpack ~ Fast Fourier Transforms Pack  
integrate ~ Integration (scipy.integrate)
interpolate ~ Interpolation (scipy.interpolate)
io ~ File IO (scipy.io)
linalg ~ Linear Algebra (scipy.linalg)
ndimage ~ Multidimensional Image Processing (scipy.ndimage)
odr ~ Orthogonal distance regression
optimize ~ Optimization (scipy.optimize)
signal ~ Signal Processing (scipy.signal)
sparse ~ Sparse Arrays 
spatial ~ For Spatial Data Structures and Algorithms
special ~ Special Functions related to Mathematics.
stats ~ Statistics Operation on Data.
